WHAT HAS BEEN DONE

The latest partition study gives:
- A join partition exactly summarizes the equality consequences of checks.
- The existing COMMIT rule tests exact checked-partition membership. Replacing
  it with entailment changes behavior; this is not a semantics-preserving fix.
- For a finite sound closure policy c at fixed key K, the permission-state
  count is 1 + |{c(T): nonempty T subset of sound claims at K}|.
- Over all partitions, exact membership needs B_n permission bits, whereas
  anchored entailment has B_n+1 abstract permission states. These component
  bounds count usable history; they are not total-machine bit counts.
- Requiring an actual current check is essential if retaining the three-stage
  sequence and three-mark floor. Without it, a tautology can bypass CHECK.
- Complete-partition inputs admit Theta(n log n) structural bits and tight
  Theta(n) worst-case SET/CHECK/COMMIT, using sparse graph components for joins.
- Pair claims under exact matching need Theta(n^2) bits and constant-time
  fixed-epoch membership operations. Inference becomes incremental connectivity.
- A logged rollback simulator transfers WORST-CASE connectivity lower bounds
  despite failed COMMIT trapping. The proof counts log memory and restores
  ledger, trap and control state. This does not transfer amortized guarantees.
- Published Pătraşcu–Thorup / Boolean union-find bounds apply through that
  reduction. The simple supplied pair implementation is O(log n), not the
  more elaborate literature-optimal O(log n/log log n) implementation.
- Ledger marks are preserved but do not price runtime or heat. Unbounded
  ledger arithmetic and storage are explicitly accounted for separately.

Earlier machine-preservation results include seven additional freshness bits
given the retained ordered fact names, sixteen historical-edition gap bits
with channel identity separate, and a finite-capacity injective-retention
bound M >= N + T(N-L) for repeated idempotent reset under stated assumptions.
Do not turn these into a seven-bit whole machine or a universal heat floor.
