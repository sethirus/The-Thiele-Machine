All three result theorems are closed under the global context. In the frozen
finite positive-weight model, uniqueness up to schedule: REFUTED. Equal branch
support and equal branch charges do not determine the branch weights. A
deterministic event also cannot produce both false and true from the same
current false reading. For this model, the probability kernel must be preserved
in addition to the schedule.

The strengthened relation used here preserves ordered weight lists exactly.
Its reflexivity is only a well-formedness check. This item does not prove that
this is the coarsest useful probabilistic equivalence, and it does not identify
kernels that normalize to the same rational distribution after common
rescaling or permutation.

## Hollowness checks

### `deterministic_latch_handles_branching`

- Definitional: not a restatement; two concrete positive branches force one
  deterministic event value to be both false and true.
- Built in: honesty requires positivity, totality, permanence, and priced
  writes, none of which rules out branching.
- Vacuity: `fair_branch_kernel` and `fair_branch_honest` close every premise.
- Swap test: swapping the branch order or renaming the Boolean observations
  leaves the branching contradiction.
- Adversarial read: PASS.

### `schedule_determines_probabilities`

- Definitional: not a restatement; the counterexample compares weights `1,1`
  with `1,2` under identical support and charges.
- Built in: `same_probabilistic_schedule` deliberately forgets weights, making
  the tested boundary explicit rather than assuming probability equality.
- Vacuity: both `fair_branch_kernel` and `biased_branch_kernel` have closed
  honesty proofs.
- Swap test: any unequal positive weights on the same supported branches give
  the same obstruction.
- Adversarial read: PASS.

### `probability_preserving_equivalence_reflexive`

- Definitional: hollow as a substantive result; it is reflexivity of two
  pointwise equalities.
- Built in: the answer follows directly from the definition.
- Vacuity: every kernel and charge function is related to itself.
- Swap test: fully polymorphic in the selected kernel and charges.
- Adversarial read: PASS; the public sentence calls it only reflexivity, not
  uniqueness.

The semantic test was red before the model, proofs, and report existed. The
guarded Coq build then closed both counterexamples and the reflexivity check.
All predictions were correct. Calls made: use finite natural weights, compare
support and prices separately from weights, and refuse to generalize the
reflexivity check into a uniqueness theorem. No novelty claim is made.
