## Exact model

A multi-valued record takes values in `A`, equipped with the Boolean-decidable
partial order `BoolPartialOrder A`. A record grows when each value is below
its successor. It is computation-driven when the successor value is a
function only of the visible base state and the current record value.

For every possible `a : A`, the threshold observation is `a <= record`.
`threshold_latch_factorization` says every such observation evolves as a
Boolean latch whose event may read `a`, the base state, and the current record
value. The entire threshold family is exact because
`thresholds_determine_record` says equal lower sets imply equal values.

The schedule is explicit. `record_schedule_priced` charges every strict
record-value change at least one ledger unit.
`threshold_schedule_priced` charges every false-to-true threshold change.
No physical calibration, canonical price above that floor, or comparison of
different bases is included.

`single_latch_carries` is the literal Round 4 one-bit form: the record value
must decode from the current base state and one permanent Boolean latch.
`chain_needs_bits` states the finite lower bound for pairwise distinct,
pointwise-monotone Boolean vectors.

Combined prediction: the Round 4 form does not extend as base plus one Boolean
latch plus schedule. It extends as base plus a complete family of threshold
latches plus schedule. A finite strict chain through `n` values requires at
least `n - 1` Boolean coordinates in the frozen vector model.

## Three strategies before BLOCKED

1. Threshold construction: use the frozen driving function at each threshold
   and permanence from the partial order to obtain the latch equation; use
   reflexivity and antisymmetry to reconstruct values.
2. Schedule equivalence: for a strict growth from `x` to `y`, use threshold
   `y` as a newly true witness; in the reverse direction, a changing threshold
   directly proves the record values differ.
3. Finite obstruction and rank: refute one-latch sufficiency with a fully
   priced three-value chain over a one-state base; prove the Boolean-chain
   bound by the strictly increasing number of true coordinates. If either
   construction fails, try direct finite enumeration as a distinct strategy.
