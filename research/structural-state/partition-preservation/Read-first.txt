Work from the existing abstract model. For each proposed simplification,

The partition example now supplies a concrete answer, independent of the

THE RESULT IN ORDINARY TERMS

Put three objects on a table, all with the same key.

One run checks that all three belong together, twice.
Another checks that all three belong together, then separately checks the
first two together with the third in its own bucket.

Both runs establish exactly the same equality facts. Both cost two marks.
But the current rule permits the second run to commit that second grouping
and makes the first run trap. It requires that grouping to have been checked
specifically, even though its truth already follows from the stronger check.

That difference is a precise design choice. It is not a dispute about Coq,
counter machines, or the speed of an interpreter.

WHAT IS PROVED

1. Several checked groupings have one exact mathematical summary: combine
   their equality relations and close them under transitivity. This is their
   join partition. It determines every grouping implied by the checks.

2. That summary does not retain the current exact-check permission rule.
   For all partitions of n objects, that rule requires B_n bits of retained
   permission state, where B_n is the number of partitions. The lower bound
   holds even when the key, ledger, channel, record, trap status and number
   of executed actions are fixed. A membership vector attains the bound.

3. An alternative rule may permit any grouping implied by actual current
   checks. Its permission component needs only B_n+1 distinguishable states,
   encodable in ceil(log2(B_n+1)) bits. One state means no current check;
   the other states identify the combined established partition.

   For five objects: the exact-check component needs 52 bits; the inferred
   component needs 6. These are abstract encoding bounds, not total machine
   memory or efficient-update claims. Usable external history must be counted.

4. Requiring an actual current check matters. Without that requirement, the
   always-valid claim "each object is in its own bucket" could be committed
   and certified from a clean start for two marks. Retaining whether any
   current check occurred preserves the three-stage order and tight minimum
   of three marks. The inferred claim need not itself have been checked
   verbatim; its justification may combine several checks. This is an
   explicit alternative policy, not the original same-claim theorem.

5. Neither structural summary determines the execution bill. Checking the
   same grouping twice can leave the structural effect unchanged while
   charging twice. Priced execution paths or a ledger must retain that
   difference. An additive cost on maps identified solely by their effects
   cannot positively price an idempotent check or reset.

The full note also proves the online update rule for any sound closure
policy, with exact matching and full entailment as two instances.

WHAT THIS MEANS FOR THE PROJECT

There is now a precise comparison between two ways of connecting established
structure to permitted actions. The difference in required state comes from
what that connection promises to preserve. The work is about the abstract
partition model already present in the project, not a new counter-machine
implementation or a data-structure detour.

This does not establish a new law of nature or a solved open problem.
The proofs use classical partition and distinguishability arguments, and no
novelty claim has been established. Positive ledger prices are specified
rules here; physical heat costs do not follow from these state counts.

The next substantive question is the computational cost of maintaining the
chosen inference policy, with the claim language and history interface made
explicit. The exact state counts above are a starting point, not a claimed
memory-time trade-off. A new result should extend or separate these concrete
bounds before it becomes additional book material.
