PROTECTED ONLINE EVIDENCE: A PRECISE MODEL AND FIRST BOUNDS
Research working note for Devon Thiele — 12 October 2026
Separate from the book. No claim of a new literature result is made here.

WHAT THIS NOTE ESTABLISHES
For a concrete online freshness invariant, the minimum persistent protected
state is exactly n bits when n claim statuses can vary independently. An exact
space/time threshold for global invalidation follows from known succinct data
structures. With arbitrary overlapping dependencies, the monitor contains
online Boolean matrix–vector multiplication as a special case. This yields
a conditional barrier to simultaneously fast operations. Explicit eager and
lazy constructions expose where the work moves. A complete tight frontier for
all claim languages and budgets is not established.

1. DEFINE THE GUARANTEE BEFORE PRICING IT

There are m mutable objects and n named claims. Claim i has a fixed declared
dependency set D_i contained in {0,...,m-1}. The dependency description is trusted
immutable policy. A write to any member changes the edition to which evidence
for claim i would refer, even if the value is later restored.

The monitor receives a serialized stream of atomic events:

  PASS(i): a trusted validator has just successfully checked claim i against
           its current object editions. Record that evidence as fresh.
  WRITE(j): a mediated write changes object j's edition. All evidence depending
            on j becomes stale.
  USE(i): allow reliance on fresh evidence for claim i, or reject it.

Let fresh_i(h) mean that h contains a PASS(i) later than every WRITE(j) with
j in D_i. Without a PASS(i), fresh_i is false. Required behaviour is

                 USE(i) accepts iff fresh_i(h).

The forward implication is soundness. The reverse implication is completeness
for this history policy. Recomputing a true predicate without the required PASS
history does not satisfy it. Nor may the monitor reject every USE: that would
be sound but would solve the wrong problem with zero persistent memory.

The adversarial program chooses requests and interleavings, controls ordinary
mutable memory, and may restore old data or replay ordinary messages. It cannot
write protected metadata, bypass mediation, impersonate PASS, or interleave a
write inside a supposedly atomic validation. A request to CHECK is not PASS:
the trusted validator must first succeed. A USE guard and its protected action
must execute at the declared atomic/linearization point; returning a free-standing
permission bit does not protect a later unmediated action.

This is a reference-monitor trust boundary, not a proof of physical tamper
resistance. Unauthenticated mutable storage is not an additional reliable
memory resource. All mutable metadata used across events counts toward the
protected budget. Authenticated external storage with computational security
is a different model, discussed in section 9.

With deterministic sound validators, complete dependencies and complete write
mediation, freshness implies that the successful validation concerned the
current editions, and hence its predicate still holds. The proof is simple:
no dependency has changed since the successful validation. This does not say
the predicate is useful, nor that an outside observer can authenticate the
device from an arbitrary message.

This research monitor is not the book's entire Small Machine. In particular,
it answers a current-freshness question; it is not the permanent ever-certified
flag, a ledger, a channel, or the ordered bounded fact table. Its memory bounds
must not be advertised as bounds for all of those fields together.

2. RESOURCE MODEL

B: mutable protected bits retained between events (quiescent state).
W: temporary protected workspace used during an event, erased or recomputable
   before the next event. If measuring peak protected storage, count B+W.
P: immutable policy representation, including dependency sets and any indexes.
T_pre: preprocessing time for that policy.
tau_p, tau_w, tau_q: metadata time for PASS, WRITE, USE respectively.
C_i: actual time needed to validate the mathematical/data predicate for claim i.

A successful CHECK therefore costs C_i plus tau_p. No theorem here replaces
that validation cost by one physical or computational unit. Expressive arbitrary
predicates can have arbitrarily expensive or undecidable validation problems.

For time bounds use a word RAM, counting reads, writes and arithmetic, with
w-bit words sufficient to address the stored data. For the hardness result
w=Theta(log n), with m=n and polynomial space. Fixed configuration such as n
may be immutable; if kept in mutable protected registers, count it in B.

Query time cannot be omitted: work postponed by an update may reappear at USE.
Similarly, a claim family is not described just by its cardinality. Its history
semantics, dependency geometry, and validation complexity all matter.

3. EXACT INFORMATION LOWER BOUND

Theorem 1. Suppose every subset of the n claims is reachable as the set of
fresh claims while the public data are identical. Every deterministic exact
monitor requires B >= n. An eager n-bit vector suffices.

Proof. Choose a history h_S for each S subset of {0,...,n-1}. If two distinct
subsets S,T left the same protected state, choose i in their symmetric
difference and issue the same USE(i). With identical public inputs and monitor
state, the deterministic monitor gives the same answer, contradicting exactness.
Thus at least 2^n states, or n bits, are needed. For sufficiency, store one bit
per claim: PASS sets its bit; WRITE(j) clears every bit whose D_i contains j;
USE reads the bit. Induction over events proves the invariant. This is a bound
on information, not on the speed of updating its representation.

The reachability premise holds, for example, when all claims can pass at one
unchanging public configuration: issue PASS for precisely the desired subset.
If those patterns are not all realizable, count realizable distinguishable
histories instead. Even logically equivalent predicates may require independent
history bits if the required answer concerns whether each named check occurred.

More generally, for a total deterministic finite-alphabet history specification,
define h~h' when every future event continuation z and every permitted claim
query require identical answers after hz and h'z. This is a right congruence.
If it has K classes, a monitor needs at least ceil(log2 K) bits and the quotient
transition system attains K states. Infinite index rules out finite protected
state in this event-only model. This is the classical residual-state/Myhill–Nerode
principle, not new mathematics. The quotient construction alone promises neither
an efficient transition algorithm nor a small immutable transition table.

Capacity variant (a different admission policy). Suppose successful validation
may be admitted to the retained evidence set only if there is room. Admission
of a new distinct claim at capacity is rejected, so it does not generate PASS.
If all and only subsets of at most k retained fresh claims are reachable and
every claim is separately queryable, the information minimum is
              ceil(log2(sum_{r=0}^k binomial(n,r))).
Enumerative encoding attains that state count, without a fast-operation promise.
An ordered table with observable duplicates has a different state count.

4. A TIGHT SPECIAL CASE: ONE WRITE INVALIDATES EVERYTHING

Take D_i={x} for every i. PASS inserts i, WRITE(x) clears the set, USE tests
membership. There is no limit on execution length.

Theorem 2. With exactly n mutable bits between operations, some global reset
requires Omega(n/w) word writes, for n growing faster than w.

Proof. The 2^n fresh subsets exhaust all 2^n memory patterns. Each subset,
including the empty one, has a unique pattern. The bitwise complement of the
empty pattern therefore represents a reachable subset. Resetting from it must
change all n bits. Each word write changes at most w of them. This argument
allows arbitrary encodings and O(w) temporary workspace; extra persistent
registers would invalidate the exactly-n-bit premise.

A plain packed bit vector attains Theta(ceil(n/w)) worst-case reset time and
constant PASS/USE time. But adding persistent redundancy can change the answer:

Known upper bound. Hagerup's externally sized atomic choice dictionary supports
insertion, membership and clear-all in constant worst-case time with n+1 bits
between operations and O(w) transient workspace. This is Theorem 1.2 of An
Optimal Choice Dictionary, under its stated word-RAM operations. The size n
is available separately. Thus the n-versus-n+1 threshold is already known and
is tight in this model when w=o(n). It is not a new result of this project.
https://arxiv.org/abs/1711.00808

GlobalSparseSet in monitors.py is an elementary executable alternative: two
index arrays and a live-prefix length support constant-time insert, membership
and reset using O(n log n) bits. It is NOT an implementation of the n+1-bit
construction. Its membership check validates both the sparse index and the
dense entry, so stale entries after reset cannot resurrect a claim.

5. ARBITRARY OVERLAP: AN OMv REDUCTION

Theorem 3. Consider monitors for arbitrary n claims on n objects with trusted
dependency matrix A, A_ij=1 iff j is in D_i. Suppose a uniform implementation
has T_pre=O(n^2 polylog n) and word size Theta(log n). If, for some fixed
epsilon>0, all three metadata times tau_p,tau_w,tau_q are O(n^(1-epsilon)),
then online Boolean matrix–vector multiplication has a truly subcubic algorithm.
The same implication holds for bounds amortized over the complete event sequence.

Proof. Preprocess A as the monitor's dependency policy. For each online input
vector v, before receiving the next vector:
  (a) issue PASS(i) for each i;
  (b) issue WRITE(j) for each v_j=1;
  (c) output not USE(i) for each i.
After (a), all claims are fresh. Following (b), claim i is stale exactly when
some j has both A_ij=1 and v_j=1. Therefore the output in (c) equals the Boolean
matrix–vector product Av. This uses no oracle for Av, no bulk refresh primitive,
and at most 3n monitor operations per vector. The same monitor is reused in
every round, so individual PASS operations must be included in the time bound.

For n vectors total time is
       O(T_pre + n^2 * (tau_p + tau_w + tau_q + 1)).
Under the displayed bounds this is O(n^(3-delta)) for some delta>0, contradicting
the OMv conjecture. PASS is the metadata handler of a trusted successful check;
the reduction invokes that handler on authenticated event symbols. It does not
claim that arbitrary predicates can actually be evaluated in constant time.

This is a reduction to the conjecture, not an unconditional time lower bound.
It rules out a uniform polynomial improvement of ALL three operations for ALL
dependency matrices under the stated preprocessing bound. It neither says every
matrix is hard nor proves a particular write must take linear time. Allowing
near-quadratic preprocessing was deliberate; arbitrary preprocessing is not
silently included in this direct argument. Polynomial-space monitors with this
preprocessing bound are covered regardless of how much extra mutable metadata
they use.

The OMv conjecture is from Henzinger, Krinninger, Nanongkai and Saranurak (2015).
It asserts that for every constant epsilon>0 no algorithm solves n online
Boolean products in O(n^(3-epsilon)) total time with error probability at most
1/3. Our deterministic exact reduction falls inside that model.
https://arxiv.org/abs/1511.06773

The single-round core is also a static-family set-disjointness problem: mark
the written object set T and ask whether D_i intersects T. Pătraşcu's multiphase
problem and later dynamic-query lower bounds are therefore direct comparison
targets. This relationship is established; this note does not claim priority
for expressing a monitor using it.

6. MATCHING CONSTRUCTIONS AT USEFUL ENDPOINTS

EAGER, SPACE MINIMUM
Store the n-bit freshness vector. Immutable policy stores the n-bit column mask
C_j for each object. WRITE(j) computes fresh := fresh AND NOT C_j, processing
ceil(n/w) words. PASS and USE access one bit in constant time. Space: B=n bits
(with a packing convention that does not make padding extra state); P=O(nm)
bits for columns; W=O(w). Preprocessing O(nm). This works for arbitrarily long
executions and completely arbitrary overlapping dependencies.

Alternatively, store incidence lists and clear only the deg(j) affected bits,
giving O(1+deg(j)) WRITE time. Keeping both policy indexes lets the implementation
choose the cheaper method, with O(1+min(deg(j),ceil(n/w))) WRITE time. Reading
the static policy and its indexes is counted. When each write affects O(1)
claims, all operations have constant worst-case metadata time at B=n.

For m=n and w=Theta(log n), the dense eager scheme has worst-case event time
O(n/log n). The OMv reduction rules out O(n^(1-epsilon)) for all events. These
bounds match only at the polynomial exponent, NOT at logarithmic factors or
as an exact three-way time trade-off.

LAZY, FINITE EXTRA STATE
Store the last PASS time c_i for each claim, the last WRITE time a_j for each
object, and answer
        fresh_i iff c_i>0 and a_j <= c_i for every j in D_i.
The times only need to preserve their order. Unbounded counters are unnecessary.

Here is an explicit bounded implementation. Let N=n+m. Maintain N token stamps
in 0..2N, where 0 means absent. Every nonzero stamp is distinct. A slots array
of length 2N maps occupied stamps to token identifiers. PASS/WRITE moves its
token to a new greatest stamp, clearing its previous slot. When the next stamp
would exceed 2N, scan the slots in increasing order and rank the live tokens
1,...,r. Update their stamps and compact the occupied slots in place. Then
continue at r+1. At most N tokens are live, so at least N further updates fit
before the next compaction.

Theorem 4. This scheme has O(N log(N+1)) persistent protected bits, O(w)
workspace, O(1) amortized PASS/WRITE metadata time, O(N) worst-case compaction
time, and O(1+|D_i|) worst-case USE time, for w=Omega(log(N+1)). It is exact
for arbitrarily long streams without wraparound or a cryptographic assumption.

Proof. At each event the order of stamps agrees with the order of surviving
last events. Rank compaction preserves that order and the absent marker, so it
preserves every comparison used by USE. A new greatest stamp implements the
next last event. Scanning and renumbering 2N slots takes O(N) operations, and
successive compactions are separated by at least N updates. This proves the
amortized bound. All cells hold values bounded by 2N or token IDs bounded by N.
Writing compacted entries earlier in the array does not overwrite an unscanned
entry. The implementation is BoundedLazy in monitors.py.

This upper bound shifts the burden to querying dependencies; it does not beat
Theorem 3. It is not asserted to be an optimal order-maintenance data structure.
A plain modulo timestamp is unsound: a check at stamp 1 followed by writes at
2, 3 and 0 can wrongly look fresh again. Rank compaction preserves order;
wraparound does not.

7. WHAT CLAIM EXPRESSIVENESS CHANGES

For finite named claims in this model, n controls a state-count lower bound.
The family {D_i} controls how write events interact with that state. These are
different axes. All dependencies may be global and still admit constant-time
operations; arbitrary overlap can encode a hard matrix. Maximum claim arity
alone therefore does not characterize difficulty.

The actual predicates add another axis: validation complexity C_i. The same
freshness data structure can sit behind an expensive verifier or a cheap one.
No bound depending on n alone can bound validation for arbitrary decidable
predicates. A language allowing undecidable predicates needs further restriction
before a total exact validator can exist.

For history languages, the residual-state count in section 3 replaces n.
For a claim universe of size U with up to k independently retained facts, the
state-count expression uses U in place of n. Unboundedly many separately
queryable identities cannot be retained exactly in a fixed finite state space.
But a single ever-occurred question needs only one bit. The observer's requested
distinctions must be specified before making a memory claim.

In particular, unbounded edition numbers in one implementation do not prove
that unbounded protected memory is necessary for a fixed finite set of current
freshness queries. Both constructions here refute that inference. Keeping
permanent unique edition identities or validating indefinitely replayable
external tokens is a stronger specification and needs its own lower bound.

8. THE HONEST STATE OF THE TRADE-OFF

Settled here, under the explicit model:
- n independent freshness bits: exactly n persistent protected bits necessary
  and sufficient, regardless of online running time.
- Global invalidation: exact-n-bit reset requires Omega(n/w); n+1 bits suffice
  for constant time with Hagerup's O(w) transient workspace and word-RAM model.
- Arbitrary overlap: the displayed OMv reduction prohibits uniformly truly
  sublinear PASS, WRITE and USE under that conjecture and preprocessing budget.
- Eager and bounded-lazy constructions give complementary time/space endpoints.

Not settled here:
- A sharp function of B, tau_p, tau_w, tau_q and the dependency family for
  every intermediate memory budget.
- The maximal classes of overlapping dependencies admitting fast operations.
- Exact deterministic frontiers when evidence lives in hostile external storage.
- Concurrent, crash-recoverable, or distributed enforcement with a specified
  consistency and rollback model.

These are research boundaries of this note, not declarations that the literature
has no answers. General finite-monitor minimization, succinct dictionaries,
dynamic set-disjointness and dynamic database-query evaluation already address
large parts of the problem. A new contribution must improve or separate a
precisely identified case after comparison with those results.

9. CHANGING THE TRUST MODEL CHANGES THE MINIMUM

The n-bit bound is for exact deterministic monitoring whose reliable mutable
metadata are wholly counted as protected. Allowing a small protected digest
and authenticated external data changes both the adversary and the success
conditions. Computational authentication, a security parameter, proof access,
availability, rollback protection, and update/query verification time must all
be stated. An adversary that deletes every witness can prevent completeness
unless availability is supplied separately. A computationally secure construction
does not refute a zero-error bound against unrestricted adversaries.
