Partition safety: the unbounded induction argument for A3-A8

Run python3 scripts/formal_prepare.py --run cpu_prove_pt. The runner requires
321 successful obligations and saves each script, log and a hashed input
manifest under build/formal/cpu_prove_pt. A missing, failed or timed-out case
cannot produce PASS. The original PDR task remains available directly in sby.

J consists of A3-A5 and the auxiliary bound base[i] <= 255 for every slot,
including empty slots. Empty bases need not be inside the 128-word memory.
The reset obligation establishes J and pairwise disjointness for arbitrary
six-bit indices. It assumes nothing about the state before reset.

The frame obligation proves A8 for arbitrary opcodes and states: outside a
retiring partition instruction, every table word and the allocation counter
stay unchanged, except on reset. Three further obligations preserve J and
prove A7 for PNEW, PSPLIT and PMERGE. They retain the original environment
contract that start is called only while halted (loader property S1).
Together these four steps and the reset base prove J for every execution.

For A6, split on the old allocation counter (1 through 64, exhaustive by J)
and partition opcode (0, 1, 2). The 316 steps together quantify over two
arbitrary table indices. Its old-state premises are J and six pairwise
disjointness facts involving those indices and the two source indices. Every
premise follows from the global induction hypothesis. The step asserts
disjointness of the selected pair after the transition. Non-partition steps
preserve it by A8; reset establishes it by the base obligation. This proves
A6 for every pair and every finite execution from reset.

For PSPLIT at old counters 1..62, three pair cases are mandatory: neither
index names a new child, the first index is the left child, and the first
index is the right child. Disjointness and all six old pair premises are
symmetric in the two indices, so reversing a pair covers the cases where
its second index is a child. Together these cases exhaust all pairs, including
the two siblings. Counters 63 and 64 cannot allocate two children and use the
unsplit obligation. Fixing a child index fixes only the arbitrary observer,
never a table entry or the allocation counter after the transition.

The SAT sequence length of two represents one arbitrary transition, with a
history register recording its premises. It does not bound the length of
the execution proved. Only the OLD allocation counter is constrained in a
case; the new counter and all table updates use the original RTL equations.

All obligations overapproximate the nine RAM read signals with arbitrary
values. The A6 steps additionally overapproximate step eligibility with an
arbitrary bit. These remove restrictions on behavior; they do not assume the
desired table updates or replace the table, arithmetic or register widths.
The extracted CPU source is unmodified. Added history and assertions observe
it and never drive it. Assertion counts and Yosys structural checks are
mandatory before solving. CPU control and loader proofs remain separate jobs.
