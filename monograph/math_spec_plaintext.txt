                                             Abstract

        The book, The Thiele Machine: No Free Insight, argues everything in plain words, with
    the reader, and leaves out theorem statements on purpose. This companion gives the exact
    statements: the definitions with every quantifier written out, and each result the book shows,
    with its hypotheses, in the book’s order. Each result is tagged with its kind from the ledger
    of Chapter 22: [shown] for an argument, [chosen] for a definition or a price, [assumed] for
    a claim about the world that an argument leans on, [cited] for somebody else’s result, and
    [thesis] for a claim no argument can settle. Where a proof is short it is printed; otherwise
    the pointer says where the book argues it. Nothing here goes beyond the book. A statement
    that looks stronger than the book’s is a mistake in this document.

1    Notation

N = {0, 1, 2, . . . }. For a finite set X, |X| is its size. log2 is the logarithm base two and ln the
natural logarithm.
A machine is a triple (S, I, δ): a set S of states, a set I of moves, and a step δ : S × I → S. A
machine with one next state is the case |I| = 1, written as a function f : S → S. A run from s
along a list of moves τ = i1 · · · in is the list of states s0 = s, sk = δ(sk−1 , ik ); run(τ, s) = sn .

A reading is a function r : S → R into a preorder (R, ≤): a reflexive, transitive relation. The
two-point reading takes values in {no, yes} with no < yes. A move i settles more at s when
r(δ(s, i)) ̸≤ r(s). On the two-point reading that is exactly r(s) = no and r(δ(s, i)) = yes.
A price list is c : I → N. Where a result lets the price depend on the state a step starts from, it
says so and writes c : S × I → N. The price of a run is the sum of the prices of its moves.
A window is a function π : S → B. The pile behind a picture b ∈ B is π −1 (b).

2      The definition

Definition 2.1 (The toll). [chosen] A price list c obeys the toll for a reading r on a machine
(S, I, δ) when
                    ∀s ∈ S, ∀i ∈ I : r(δ(s, i)) ̸≤ r(s) =⇒ c(i) ≥ 1.

Definition 2.2 (Thiele machine). [chosen] A Thiele machine is a machine (S, I, δ) with a
reading r : S → (R, ≤), a price list c : I → N, and a set S0 ⊆ S of starts, such that

    (i) (settled never goes back) r(s) ≤ r(δ(s, i)) for every s ∈ S and i ∈ I;

 (ii) (something settles) there are s0 ∈ S0 and a list of moves τ with r(run(τ, s0 )) ̸≤ r(s0 );

 (iii) (the toll) c obeys the toll for r.

Prices are in N: nothing or more, never a refund.

Remark 2.3. Clause (ii) rules out a machine that never settles anything, which would meet (i)
and (iii) for free. Prices in N rule out a later move paying back an earlier charge. The smallest
reading is the two-point one, and most results below are stated on it; a checklist of k boxes
whose ticks never come off is the reading into {no, yes}k ordered coordinatewise.

Argued in Chapter of the book.

Definition 2.4 (Established record). [chosen] Let a machine carry a two-point reading r (the
box), a set of claims C, for each claim κ ∈ C a set of check moves and a relation saying which
moves touch what κ is about, and a predicate saying whether a check of κ passes at a state. A
start is clean when its box is down. The box is established for κ when, on every run from a clean
start, every step that turns the box up is preceded in that run by a step that is a passing check
of κ, with no move that touches what κ is about between that check and the raise. The box is
still a reading of a Thiele machine, so the step that turns it up pays the toll. That the check
means what it says and could have failed is a fact about the checker, not a condition on the
machine.

Argued in Chapter 8 of the book.


3      Any machine that steps

Throughout this section f : S → S is a machine with one next state and x0 ∈ S is a start. The
run from x0 is xn = f n (x0 ) for n ∈ N.

Definition 3.1 (Fresh steps, meeting on a run). [chosen] The step from xn is fresh when
xn+1 ∈
     / {x0 , . . . , xn }. Two arrows meet on the run within n when there are i, j ≤ n with xi =
                                                                                               ̸ xj
and f (xi ) = f (xj ). Two arrows meet on the run when they meet on it within some n.

Definition 3.2 (Turing’s machine). [cited] Turing’s model, in the form used here: a finite
alphabet Σ with a blank ⊔ ∈ Σ, a finite set Q of letters, and a table, a partial function
τ : Q × Σ ⇀ Q × Σ × {−1, 0, +1}. A configuration is a triple (q, h, w) with q ∈ Q, h ∈ Z the
head, and w : Z → Σ the tape, blank at all but finitely many cells. If τ (q, w(h)) = (q ′ , σ, d), the
next configuration is (q ′ , h + d, w′ ), where w′ (h) = σ and w′ (p) = w(p) for p =
                                                                                   ̸ h. If τ (q, w(h)) is
undefined, the configuration has no next configuration and is stopped.



                                                   3
Remark 3.3. A configuration is the whole state: the table does not change, and the next
configuration is a function of the configuration alone. So a Turing machine is a machine with
at most one next state, with the configurations as states. The claims that other models of
computation compute the same functions as Turing’s are [cited]. The Church-Turing thesis, and
the claim that every machine that can be built is covered, are claims about the world; no result
in this document rests on them.

Argued in Chapter 1 of the book.
Proposition 3.4 (The step law). [shown] Let f : S → S and x0 ∈ S, with no condition on S.
For every n ∈ N the step from xn does one of the following, and (a) excludes (b) and (c):

 (a) it is fresh;

 (b) xn+1 = xj for some j ≤ n with j = 0 or xj−1 = xn (it goes round a loop: back to the start,
     or along a step the run has taken before);

 (c) xn+1 = xj for some 1 ≤ j ≤ n with xj−1 ̸= xn (two arrows meet: f (xj−1 ) = f (xn )).

If some step is not fresh, let the step from xn be the first, landing on xj with j ≤ n. Every
earlier step is fresh; either j = 0, or j ≥ 1 and xj−1 ̸= xn , so two arrows meet; and from xj on
the run repeats with period p = n + 1 − j: xk+p = xk for all k ≥ j.

Proof. If xn+1 ∈/ {x0 , . . . , xn }, (a) holds. Otherwise xn+1 = xj for some j ≤ n; if j = 0 or
xj−1 = xn that is (b), and else (c). At the first revisit, x0 , . . . , xn are pairwise distinct, so for
j ≥ 1 the states xj−1 and xn are distinct (j − 1 < n), and both step to xj . Since f is a function,
xn+1 = xj gives xn+1+m = xj+m for every m, which is the period.

Argued in Chapter 1 of the book.
Proposition 3.5 (Keeping on any number of states). [shown] Let f : S → S, and let r : S →
{no, yes} be a two-point reading that never goes back under f : r(s) = yes implies r(f (s)) = yes.
Let r(x0 ) = no and r(xm ) = yes for some m. Then xk ̸= x0 for every k ≥ 1, and either the
states x0 , x1 , x2 , . . . are pairwise distinct, or two arrows meet on the run. No condition on S is
used.

Proof. If xk = x0 with k ≥ 1, then xqk = x0 for every q ∈ N. Take q with qk ≥ m; since
the reading never goes back, r(xqk ) = yes ̸= r(x0 ), a contradiction. So no step goes round a
loop through the start. If the states are not pairwise distinct, some step is not fresh, and by
Proposition 3.4 the first such step lands on xj with j ≥ 1 and makes two arrows meet.

Argued in Chapter 1 of the book.
Proposition 3.6 (A machine that stops slips past the merge). [shown] Let S = {w, h} with
w ̸= h, a partial step f with f (w) = h and no next state for h, and r(w) = no, r(h) = yes. The
run from w raises the reading, keeps it, visits two states, and no two arrows meet. Let g : S ′ → S ′
be any total step on a set S ′ ⊇ S with g(w) = h, and r extended to a two-point reading on S ′
that never goes back under g. Then the run of g from w visits pairwise distinct states forever, or
two arrows meet on it. In particular, g(h) = h gives g(w) = g(h); and g(h) = p, g(p) = p with
p∈/ S gives g(h) = g(p).

Proof. The partial step has one arrow, so no two arrows meet. The statement about g is
Proposition 3.5 for g from w. The two particular cases are direct.

Proposition 3.7 (A machine that stops, with a price on stopping, is a Thiele machine). [shown]
Let f : S ⇀ S be a partial step and H = S \ dom(f ) its stopped states. Let f¯(s) = f (s) for
s∈/ H and f¯(s) = s for s ∈ H (a stopped state stays where it is). Read it through whether it has

that is, f¯n (s0 ) ∈ H for some n. Then:

 (a) with one move t and c(t) = 1, the tuple (S, {t}, f¯, r, c, S0 ) is a Thiele machine, and every
     price list that obeys the toll for r has c(t) ≥ 1;

  (b) every step that stops it, from s ∈
                                       / H to f (s) ∈ H, is a step where two arrows meet: s ̸= f (s)
      and f¯(s) = f¯(f (s)).

This applies to a Turing machine, with its configurations as states, and to any machine with at
most one next state. The only datum added to the machine is the price.

Proof. (a) If r(s) = yes then s ∈ H and f¯(s) = s ∈ H, so clause (i) holds. The run of length n
from s0 ends in H while s0 ∈  / H, so clause (ii) holds. Clause (iii) holds since c(t) = 1. Some step

Proposition 3.8 (Turing’s model makes no mark hold). [shown] In Turing’s model (Defini-
tion 3.2), let τ be a table, (q, h, w) a configuration, and σ ∈ Σ any symbol. The table τ ′ that
agrees with τ everywhere except at the entry (q, w(h)), where τ ′ (q, w(h)) = (q, σ, 0), is a table of
the model, and under τ ′ the next configuration carries σ at cell h. So for every cell and every
mark, the model contains a table that rubs the mark out (σ = ⊔) and a table that prints it,
whatever came before. No condition of the model makes a mark, once written, stay.

Proof. Every partial function Q × Σ ⇀ Q × Σ × {−1, 0, +1} is a table, so τ ′ is one, and the step
rule of Definition 3.2 writes σ at h.

4    Running out of room

For a two-point reading r write Y = r−1 (yes), the done states. For a move i write δi = δ(·, i). A
move i is one-to-one when δi is; otherwise two arrows meet at i. A move i keeps done states
done when δi (Y ) ⊆ Y . Clause (i) of Definition 2.2, on a two-point reading, says that every move
keeps done states done.

Proposition 4.1 (The chairs). [shown] Let (S, I, δ) be a machine with a two-point reading r,
and Y finite. Let i be a move that keeps done states done, and s ∈    / Y with δ(s, i) ∈ Y . Then two
arrows meet at i: there are t ̸= t′ in Y ∪ {s} with δ(t, i) = δ(t′ , i).



                                                  5
Proof. δi maps the |Y | + 1 states of Y ∪ {s} into Y , which has |Y | states. By the pigeonhole
principle two of them have the same image.

Argued in Chapter 2 of the book.

Example 4.2 (The meeting need not be at the landing). S = {3, 4, 5a, 5b}, f (3) = 4, f (4) = 5a,
f (5a) = 5b, f (5b) = 5b, Y = {5a, 5b}. The step from 4 settles the answer, and no other state
lands on 5a. Two arrows meet at 5b, from 5a and 5b, one tick later on the run. The move as a
whole is not one-to-one, as Proposition 4.1 requires.

Argued in Chapter of the book.

Proposition 4.3 (Merge or fresh states, counted). [shown] Let f : S → S, r a two-point reading
that never goes back under f , r(x0 ) = no, and r(xm ) = yes for some m. If two arrows do not
meet on the run within n, then x0 , . . . , xn+1 are pairwise distinct. Consequently, if S is finite,
two arrows meet on the run within |S| − 1.

Proof. Suppose xi = xj with i < j ≤ n + 1, and take such a pair with i least. If i ≥ 1, then
f (xi−1 ) = f (xj−1 ) with i − 1, j − 1 ≤ n, so xi−1 = xj−1 since no two arrows meet within n; this
contradicts the choice of i. So xj = x0 with j ≥ 1, which Proposition 3.5 excludes. For the
consequence, take n = |S| − 1: the |S| + 1 states x0 , . . . , x|S| cannot be pairwise distinct.

Argued in Chapter 2 of the book.

Proposition 4.4 (Endless room: Hilbert’s hotel). [shown]

 (a) On S = N let f (n) = n + 1 and r(n) = yes if and only if n ≥ 1 (the strip: n marks). Then
     f is one-to-one, the reading never goes back, the step from 0 raises it, and every step of
     every run is fresh.

 (b) Conversely, let f : S → S be one-to-one, r a two-point reading that never goes back under
     f , and r(s) = no, r(f (s)) = yes. Then the states f t (s), t ∈ N, are pairwise distinct, and f
     maps Y one-to-one into Y \ {f (s)}. So Y is infinite.

Proof. (a) is direct. (b) The iterates are distinct by Proposition 3.5, since a one-to-one f never
makes two arrows meet. f (Y ) ⊆ Y because the reading never goes back, and f (s) ∈         / f (Y )
because f is one-to-one and s ∈ / Y . A finite set has no one-to-one map onto a proper subset of
itself.

Argued in Chapter 2 of the book.

Proposition 4.5 (Nothing meets on finitely many states: back to the start). [shown] Let S be
finite and f : S → S one-to-one. Every run returns to its start: xp = x0 for some 1 ≤ p ≤ |S|.
Consequently, if a two-point reading never goes back under f and r(x0 ) = no, then r(xk ) = no
for every k: the machine keeps nothing.

Proof. Among x0 , . . . , x|S| two are equal, xi = xj with i < j ≤ |S|. Cancelling f i times, which
is allowed because f is one-to-one, gives x0 = xj−i . If r(xk ) = yes for some k, then the reading
is yes at every multiple of p = j − i that is at least k, where the run is at x0 , a contradiction.

Argued in Chapter 2 of the book.

Corollary 4.6 (Several moves, none meeting). [shown] Let (S, I, δ) have S finite and every
move one-to-one, and let a reading r into a preorder satisfy clause (i) of Definition 2.2. Then
r(run(τ, s)) ≤ r(s) for every s and every list τ . So clause (ii) fails, and the machine is not a
Thiele machine for any price list and any starts.

Proof. Each δi is a permutation of the finite set S, so δipi is the identity for some pi ≥ 1, and
δi−1 = δipi −1 . Hence for t = run(τ, s) there is a list τ ′ with run(τ ′ , t) = s. Clause (i) along τ ′
gives r(t) ≤ r(s).

Argued in Chapter 2 of the book.

Example 4.7 (The cut strip). Let S = {0, 1, . . . , 8} (the number of marks on an eight-box
strip), f (n) = n + 1 for n < 8, and r(n) = yes if and only if n ≥ 1. Leaving f (8) undefined is a
machine that stops. Every choice of f (8) ∈ S either lowers the reading (f (8) = 0) or makes two
arrows meet: if f (8) = k ≥ 1 then f (k − 1) = k = f (8) and k − 1 ̸= 8.

Argued in Chapter 2 of the book.

Proposition 4.8 (How long a finite machine can hold off). [shown] Let f : S → S, r a two-point
reading that never goes back under f , Y finite with |Y | = K, x0 ∈           / Y and x1 ∈ Y . Then
two arrows meet on the run within K. The bound is exact: for every K ≥ 1, the machine
S = {u, h1 , . . . , hK } with f (u) = h1 , f (hj ) = hj+1 for j < K, f (hK ) = hK , Y = {h1 , . . . , hK },
run from u, has no two arrows meeting within K − 1, and two arrows meeting within K.

Proof. If two arrows do not meet within K, Proposition 4.3 makes x1 , . . . , xK+1 pairwise distinct,
and all lie in Y because the reading never goes back: K + 1 states in a set of K. In the example,
x0 , . . . , xK−1 are u, h1 , . . . , hK−1 , with the distinct images h1 , . . . , hK , and f (hK−1 ) = f (hK )
(for K = 1, f (u) = f (h1 )).

Argued in Chapter 2 of the book.
Remark 4.9. Whether a move is one-to-one is a fact about the move on a stated set of states.
Every merge in this document is counted on the whole state set the machine is given, and on
nothing outside it.


5     Why charge for it

The notation of Section 4 is kept: Y = r−1 (yes) and δi = δ(·, i).

Definition 5.1 (Bennett’s rule). [chosen] A price list c : I → N follows Bennett’s rule on (S, I, δ)
when every move at which two arrows meet costs at least one:

                              ∀i ∈ I :    δi not one-to-one =⇒ c(i) ≥ 1.

The rule is Bennett’s: what has to cost is the merging of two computation paths.

Argued in Chapter 3 of the book.

Theorem 5.2 (The toll follows). [shown] Let (S, I, δ) carry a two-point reading r with Y finite,
satisfying clause (i) of Definition 2.2 (done stays done), and let c follow Bennett’s rule. Then c
obeys the toll for r.


                                                      7
Proof. If r(s) = no and r(δ(s, i)) = yes, Proposition 4.1 applies, since every move keeps done
states done. So two arrows meet at i, and Bennett’s rule gives c(i) ≥ 1.

Argued in Chapter 3 of the book.

Proposition 5.3 (Merge or take back). [shown] Let (S, I, δ) carry a two-point reading r with Y
finite. No condition that done stays done is assumed. If r(s) = no and r(δ(s, i)) = yes, then two
arrows meet at i, or there is t ∈ Y with δ(t, i) ∈
                                                 / Y.

Proof. If no such t exists, i keeps done states done, and Proposition 4.1 applies.

Argued in Chapter 3 of the book.

Example 5.4 (Charged is not the same as kept). S = {T0 , T1 , T2 }, Y = {T1 }, one move f with
f (T0 ) = T1 , f (T1 ) = T2 , f (T2 ) = T1 . The move settles at T0 , takes back at T1 , and makes two
arrows meet (f (T0 ) = f (T2 )). Bennett’s rule charges it, and it keeps nothing. The implication
of Theorem 5.2 has no converse.

Argued in Chapter 3 of the book.

Proposition 5.5 (The moves Bennett’s rule forces are the merges). [shown] Let (S, I, δ) be any
machine, finite or not, and i ∈ I. Then c(i) ≥ 1 for every price list c that follows Bennett’s rule
if and only if two arrows meet at i.

Proof. If two arrows meet at i, the rule itself charges i. If δi is one-to-one, the price list with
c(i) = 0 and c(j) = 1 for j ̸= i follows the rule and does not charge i.

Argued in Chapter 3 of the book.

Corollary 5.6. [shown] Under the hypotheses of Theorem 5.2, every move that settles more
somewhere is charged by every price list that follows Bennett’s rule.

Argued in Chapter 3 of the book.

Proposition 5.7 (Three doors). [shown] Each of the three conditions of Theorem 5.2 (finitely
many done states, done stays done, Bennett’s rule) can fail while the other two hold and some
move settles more, and then the toll can fail.

 (a) The strip: S = N, one move n 7→ n + 1, r(n) = yes if and only if n ≥ 1, c = 0. Done stays
     done, Bennett’s rule holds (the move is one-to-one), the step from 0 settles, the toll fails,
     and Y is infinite.

 (b) The coin: S = {tails, heads}, one move that swaps them, r(heads) = yes, c = 0. Y is finite,
     Bennett’s rule holds, the step from tails settles, the toll fails, and done does not stay done.

 (c) The stamp at zero: S = {blank, stamped}, one move sending both to stamped,
     r(stamped) = yes, c = 0. Y is finite, done stays done, the step from blank settles, the toll
     fails, and Bennett’s rule fails.

Proof. (a) n + 1 = n′ + 1 gives n = n′ ; a state n ≥ 1 goes to n + 1 ≥ 1; the step from 0 settles at
price 0; Y = {1, 2, . . . }. (b) The swap is a bijection; it sends heads to tails. (c) Both states land
on stamped; the step from blank settles at price 0.

Definition 5.8 (The halving rule). [chosen] For a move i and y ∈ S, the pile of i at y is δi−1 (y).
A price list c follows the halving rule when each unit of cost pays for at most one halving:

                            ∀i ∈ I, ∀D ⊆ S finite :           |D| ≤ 2c(i) |δi (D)|.

Argued in Chapter 3 of the book.
Lemma 5.9 (The worst pile-up). [shown] c follows the halving rule if and only if, for every
move i, every pile of i has at most 2c(i) states. In particular a price list that follows the halving
rule follows Bennett’s rule, and a move with a pile of three states costs at least two.

Proof. If every pile has at most 2c(i) states, D is covered by its |δi (D)| piles, so |D| ≤ 2c(i) |δi (D)|.
Conversely, a finite subset D of one pile has |δi (D)| = 1, so |D| ≤ 2c(i) ; hence the pile is finite
with at most 2c(i) states. A pile of two forces c(i) ≥ 1; a pile of three forces 2c(i) ≥ 3.

Argued in Chapter 3 of the book.

Definition 6.1 (The latch). [chosen] The latch is the machine with S = {no, yes}, one move

Proposition 6.2 (The smallest Thiele machine). [shown]

7    More settled

Let (R, ≤) be a preorder. A cup on R is a map u : R → {no, yes} with x ≤ y ⇒ u(x) ≤ u(y):
once up, climbing never turns it down. The cup at a ∈ R is ua (x) = yes if and only if a ≤ x.
A row of k cups u1 , . . . , uk sends x to its arrangement (u1 (x), . . . , uk (x)) ∈ {no, yes}k , ordered
coordinatewise. The row tells places apart when the arrangement is one-to-one, and shows the
order when x ≤ y holds exactly when the arrangement of x is at or below that of y. For a
reading r : S → R, the cup at a read on the machine is the two-point reading ua ◦ r.

Lemma 7.1. [shown] Each ua is a cup. If r satisfies clause (i) of Definition 2.2, each ua ◦ r
does too: each cup, read on the machine, is a two-point reading that never goes back.

Proof. Transitivity of ≤.

Proposition 7.2 (A row of cups on a straight line). [shown]

 (a) If v0 ≤ v1 ≤ · · · ≤ vn in {no, yes}k are pairwise distinct, then n ≤ k.

 (b) For each k, the arrangements cj with the first j cups up, j = 0, . . . , k, are k + 1 pairwise
     distinct, increasing arrangements, and the row of k cups uj = uxj , j = 1, . . . , k, on the
     chain x0 < x1 < · · · < xk sends xj to cj and shows the order.

 (c) So a chain of n stages can be told apart by a row of k cups if and only if k ≥ n − 1.

Proof. (a) Each vt+1 ̸= vt with vt ≤ vt+1 has at least one more coordinate up, and there are k
coordinates. (b) xj ≥ xl exactly when j ≥ l. (c) The stages form a chain, so their arrangements
under any row of cups are increasing; if they are pairwise distinct, (a) gives n − 1 ≤ k. (b) gives
the converse.

Proposition 7.3 (Cups fix the place exactly when the order is partial). [shown] For x, y in a

of R tell places apart if and only if ≤ is antisymmetric. Without antisymmetry: let R = {ℓ, ρ}

Proof. If all cups agree, ux (x) = yes gives ux (y) = yes, that is x ≤ y, and symmetrically.
Conversely x ≤ y ≤ x and transitivity make every cup agree. In the example every pair of places

Proposition 12.1 (The diagonal). [shown] There are no positive integers p, q with p2 = 2q 2 :
the diagonal of a square is not a ratio of whole numbers to its side.

Proof. Suppose there are, and take p/q with no common factor. p2 is even, and the square of an
odd number is odd, so p = 2r. Then 4r2 = 2q 2 , so q 2 = 2r2 is even and q is even, against the
choice of p, q.

Argued in Chapter 10 of the book.

Definition 12.2 (Structure, relative to a frame). [chosen (an overlay of the sources)] A pile is a
set X. A frame on X is a set G of one-to-one maps of X onto itself (the chosen changes) that
contains the identity and is closed under composition and inverses. Relative to G, the relations
that count are the relations R ⊆ X n with g(R) = R for every g ∈ G, and x, y ∈ X are the same
when g(x) = y for some g ∈ G. Two piles with named relations carry the same structure when a
one-to-one map of one onto the other carries each named relation onto the relation of the same
name. There is no structure of a pile without a frame.

Argued in Chapter 10 of the book.

Proposition 12.3 (Sameness under a frame sorts the pile). [shown] For a frame G on X,
“g(x) = y for some g ∈ G” is an equivalence relation on X.

Proof. The identity gives reflexivity, inverses give symmetry, composition gives transitivity.

Argued in Chapter 10 of the book.

Proposition 12.4 (Sameness and sorting are one object). [shown (a textbook fact)] On a
set X, sending an equivalence relation ∼ to its classes {{y : y ∼ x} : x ∈ X} is a one-to-one
correspondence between equivalence relations on X and partitions of X into nonempty blocks;
the inverse sends a partition to the relation “in the same block”.

Proof. The classes are nonempty (x ∼ x) and cover X. If z lies in the classes of x and of y, then
x ∼ z ∼ y, so x ∼ y and the two classes are equal: blocks never half overlap. “Same block” is
reflexive, symmetric and transitive because each thing lies in exactly one block. Going one way
and back returns the relation, and returns the partition.

Argued in Chapter 10 of the book.

Proposition 12.5 (An order is a sorting with one-way doors). [shown (a textbook fact)] Let ≤
be a preorder on R (reflexive and transitive), and let x ≡ y when x ≤ y and y ≤ x.

 (a) ≡ is an equivalence relation (the buckets).

 (b) ≤ respects buckets: x ≡ x′ , y ≡ y ′ and x ≤ y imply x′ ≤ y ′ .

 (c) Between different buckets ≤ goes one way: x ≤ y and x ̸≡ y imply y ̸≤ x. So the order
     induced on buckets is a partial order.

 (d) Conversely, a partition of R with a partial order on its blocks gives, by x ≤ y when
     block(x) ≤ block(y), a preorder whose buckets are the blocks.

Removing the doors leaves the partition.

Proof. (a) and (b) are reflexivity and transitivity. (c) If also y ≤ x, then x ≡ y. (d) Reflexivity and
transitivity pass from the order on blocks; x ≤ y and y ≤ x give equal blocks by antisymmetry.

Definition 13.1 (A counter kept by a price list). [chosen] A counter machine is a machine
(S, I, δ) with a start s0 , a price list c : I → N, and a counter µ : S → N in the state with
µ(s0 ) = 0 and µ(δ(s, i)) = µ(s) + c(i) for all s and i. A state is reachable when it is run(τ, s0 )
for some list τ .

Proposition 13.2 (The total is the charges). [shown] In a counter machine, µ(run(τ, s)) =
µ(s) + c(τ ) for every state s and list τ ; so µ never decreases along a run. For any m : S → N,
m(run(τ, s)) = m(s) + c(τ ) for all s, τ holds if and only if m(δ(s, i)) = m(s) + c(i) for all s, i.

Proof. Induction on τ ; the one-step rule is the case of a list of length one.

Argued in Chapter 11 of the book.

Proposition 13.3 (Only one honest count). [shown] In a counter machine, let B : S → N satisfy
B(s0 ) = 0 and B(δ(s, i)) = B(s) + c(i) for every reachable s and every i. Then B(s) = µ(s)
for every reachable s. Both hypotheses are needed: B = µ + 1 follows the price list and agrees
nowhere; and a state no run reaches can carry any value.

Proof. Induction on the run reaching s: both start at 0 and rise by c(i) on each step.

Argued in Chapter 11 of the book.

Proposition 13.4 (A counter in the state takes fresh states). [shown] In a counter machine:

 (a) if a run visits the same state twice, the moves between the two visits cost 0 in total;

  (b) a step whose move costs at least 1 lands on a state the run has not visited before;

Theorem 13.9 (The toll as a potential; floor and ceiling). [shown] Let r be a two-point reading,
Φ(s) = 1 when r(s) = no and Φ(s) = 0 when r(s) = yes, and let c : S × I → N depend on the
state a step starts from. A step (s, i) is a raise when r(s) = no and r(δ(s, i)) = yes.

 (a) (Floor.) c(s, i) + Φ(δ(s, i)) ≥ Φ(s) for all s, i if and only if c(s, i) ≥ 1 on every raise. Then
     along every run the number of raises is at most the total price, and every run from a no
     state to a yes state costs at least 1.

                                                  25
  (b) (Floor and ceiling.) The floor together with Φ(s) ≥ c(s, i) + Φ(δ(s, i)) for all s, i holds if
      and only if c(s, i) = 1 on every raise, c(s, i) = 0 on every other step, and no step goes from
      yes to no.

  (c) (Per move.) If some move raises at some state, no price list c : I → N, the same at every

Proof. (a) Φ(s) − Φ(δ(s, i)) is 1 on a raise, −1 on a step from yes to no, and 0 otherwise; prices

Definition 14.1 (Entitlement). [chosen] A run is entitled to lean on a claim κ when three things
are on hand:

  (i) an object: a component of the states of the run;

 (ii) a checked relation: a step of the run that is a check relating that object to κ, with its

 (iii) a paid event: a step of the run that put the object in place and whose price is at least 1.

Entitlement is a statement about the run, made by whoever examines it afterwards. Nothing in
the machine requires a later step to read the object or the box.

Narrowing and the strength of a test

Let L be a set of candidates and o : L → O an observation. The test of L is the set o(L) =
{o(x) : x ∈ L} of observations some candidate in L would show; the test passes v when v ∈ o(L).

Lemma 14.3 (Narrower means a stronger test). [shown] Let L′ ⊆ L. Then o(L′ ) ⊆ o(L), and
o(L′ ) ⊊ o(L) if and only if some x ∈ L \ L′ has o(x) ̸= o(y) for every y ∈ L′ .

Proof. The inclusion is immediate. The test of L passes an observation that the test of L′ does
not exactly when some x ∈ L shows a value that no y ∈ L′ shows; such an x is not in L′ .

Example 14.4. Let L be the six orders of the cards 1, 2, 3 and L′ = {123, 132, 312}, the orders
with 1 left of 2. For the observation “is 1 left of 2”, o(L′ ) = {yes} ⊊ {yes, no} = o(L). For the
observation “is the first card a 3”, o(L′ ) = o(L) = {yes, no}, although three orders were dropped.

Lemma 14.5 (Halvings and question trees). [shown] Let C be a finite set of N ≥ 1 candidates
and let a binary tree of yes-or-no questions of depth d send each candidate to a leaf, with at most
M ≥ 1 candidates at each leaf. Then N ≤ 2d M , and

                                    d ≥ ⌈log2 N ⌉ − ⌈log2 M ⌉.

If a run has at least d steps each priced at least 1, its price is at least ⌈log2 N ⌉ − ⌈log2 M ⌉.

Proof. A tree of depth d has at most 2d leaves, so N ≤ 2d M ≤ 2d+⌈log2 M ⌉ , which gives
⌈log2 N ⌉ ≤ d + ⌈log2 M ⌉. The last sentence follows because the price of a run is the sum of the
prices of its steps.

Example 14.6. Sorting three cards by comparisons separates 3! = 6 orders down to one, so
M = 1 and d ≥ ⌈log2 6⌉ = 3. For twelve cards the bound is ⌈log2 12!⌉ = 29, and Wells’s computer
search found that 30 comparisons are needed [cited]: the bound is a floor and need not be
reached.

Lemma 14.7 (Bounded share per test). [shown] Let k ≥ 0 and let a run make t tests that
narrow a list of candidates through sizes L0 ≥ L1 ≥ · · · ≥ Lt ≥ 1, where each test keeps at least
a share 2−k of the list: Lj−1 ≤ 2k Lj for 1 ≤ j ≤ t. Then

                                    ⌈log2 L0 ⌉ − ⌈log2 Lt ⌉ ≤ kt.

If each test is priced at least 1, the halvings dropped are at most k times the price of the run.

Proof. From Lj−1 ≤ 2k Lj follows ⌈log2 Lj−1 ⌉ ≤ k + ⌈log2 Lj ⌉. Sum over j = 1, . . . , t.

What standing behind a grouping gets you

Let X be a finite set of items. A grouping is a map g : X → Λ into a set of labels; two items
share a group when they have the same label. A question is a map k : X → K. The grouping g
is sound for k when
                          ∀x, y ∈ X : g(x) = g(y) =⇒ k(x) = k(y).
A grouping h cuts g smaller (refines g) when h(x) = h(y) ⇒ g(x) = g(y) for all x, y ∈ X.
Theorem 14.9 (Soundness transfers exactly to cuttings). [shown] Let g, h be groupings of X.

 (a) Soundness depends on a grouping only through which items share a group: if g(x) = g(y) ⇔
     g ′ (x) = g ′ (y) for all x, y, then g is sound for k if and only if g ′ is.
 (b) h is sound for every question for which g is sound if and only if h cuts g smaller.
 (c) If h does not cut g smaller, there is a question with two values for which g is sound and h
     is not.

Proof. (a) The definition of soundness mentions g only through the relation g(x) = g(y). (b) If
h cuts g smaller and g is sound for k, then h(x) = h(y) gives g(x) = g(y) and so k(x) = k(y).
Conversely, g is sound for the question k = g, so h is sound for g, which says that h cuts g
smaller. (c) Take x, y with h(x) = h(y) and g(x) ̸= g(y), and let k(z) = yes when g(z) = g(x)
and no otherwise. Each group of g has one value of k, so g is sound for k; h puts x and y
together with k(x) ̸= k(y).

Remark 14.10. A grouping that does not cut g smaller can still be sound for a particular question;
when k is constant every grouping is sound. Theorem 14.9 says what soundness of g guarantees
for every question. A box that records “g was found sound for k” records it for the values of k
at the time of the check; a later change to k is not covered.

A base is a machine (B, I, β) with a set B0 ⊆ B of starts and a set H ⊆ B of stopped states.
When |I| = 1 the base has one next state; otherwise the event below may depend on the move
as well as the state.
Definition 16.1 (A box over a base). [chosen] A box machine over the base is a machine

and x ∈ HX ⇔ p(x) ∈ H. The price of a step is t(µ(x, i)) − t(x). The five rules are:

(R1) (answers only to the machine) there is F : B × I × {no, yes} → {no, yes} with ρ(µ(x, i)) =

(R5) (something turns it up) some run from a start reaches a state x with ρ(x) = no and
     ρ(µ(x, i)) = yes for some i.

Rule (R1) quantifies over every state of X, reached or not. The extra components of X beyond
the base are arbitrary.

The four doors

The four doors for keeping a shortcut honest after writes are: editions that wrap around (the
first door); editions never reused, which on a finite machine is a budget (the second); one box
knocked down by every write (the third); and a box tied to the value checked instead of the
edition (the fourth). The guard is the test that decides whether the shortcut may run; when it
says yes the shortcut is unlocked. The guard reads a memory of E boxes, {no, yes}E , ordered
coordinatewise; |m| is the number of boxes up in m. A round is: write a passing value, check it,
ask; then write a failing value, and ask again.

     memory m to some m′ ≥ m.

Let P be a set of programs with an equivalence ≈, “behaves alike”. Let R be a set of maps

pno ∈/ A. For d : P → {no, yes}, the flip of d is ϕd (p) = pno if d(p) = yes and ϕd (p) = pyes if
d(p) = no.

Remark 19.2. The argument uses only Kleene’s trick, that the flip can be run, the two examples

20     Five real systems

Throughout Sections 20 to 24, a two-point reading is called a box. The box is up at s when
r(s) = yes and down when r(s) = no. A step from s by i raises the box when r(s) = no and
r(δ(s, i)) = yes. For a list of moves τ = i1 · · · in and a start s, raises(τ, s) is the number of k
such that the step from sk−1 by ik raises the box. A machine with one next state f makes two
arrows meet on a set D when f (x) = f (y) for some x ̸= y in D.
Definition 20.1 (Fee, bond, budget). [chosen] A system prices an event when it attaches to it
one of three costs. A fee: something taken at the event itself, whatever happens afterwards. A
bond: something put at risk by the event and lost only if some stated later event happens. A
budget: a limited allowance the event draws down, so that only finitely many such events can
happen. A cost of undoing that rests only on a computation nobody knows how to reverse (a
wall) is not a price, and neither is work a system needs and never charges for.

Proof-of-stake finality

Definition 20.2 (Checkpoints, votes, finality). [chosen] Let T be a finite rooted tree of
checkpoints with root g (the genesis block), and let h(x) be the depth of x (its round). Write
x ⪯ y when x is an ancestor of y or x = y. Two checkpoints conflict when neither is ⪯ the
other. Let V be a finite set of validators with stakes w : V → (0, ∞), W = v∈V w(v), and
                                                                                          P

w(U ) = v∈U w(v). A vote of a validator is a pair (s, t) of checkpoints with s ⪯ t, s ̸= t; it is
         P

a link from s to t. A link is a supermajority link when the validators who voted it have stake
at least 2W/3. The justified checkpoints form the least set containing g such that t is justified
whenever s is justified and s → t is a supermajority link. A checkpoint s is final when it is
justified and there is a supermajority link from s to a child c of s. A validator is slashable
when it cast two votes (s1 , t1 ), (s2 , t2 ) with either t1 ̸= t2 and h(t1 ) = h(t2 ) (a double vote), or
h(s1 ) < h(s2 ) < h(t2 ) < h(t1 ) (a surround vote).

Theorem 20.3 (Accountable safety). [shown on the copy] In the setting of Definition 20.2, if
two conflicting checkpoints are both final, then the slashable validators have stake at least W/3.

Proof. Two sets U1 , U2 ⊆ V with w(U1 ), w(U2 ) ≥ 2W/3 satisfy w(U1 ∩ U2 ) ≥ w(U1 ) + w(U2 ) −
W ≥ W/3. Every justified t ̸= g has a supermajority link into it from a justified checkpoint, and
g ⪯ x for every x, so neither final checkpoint is g. Let f1 , f2 be the two, with v = h(f1 ) ≤ h(f2 ),
and let f1 → c be a finalizing link, h(c) = v + 1. If h(f2 ) = v, the links into f1 and f2 land in
round v on different checkpoints, and their voter sets share stake at least W/3, all of it double
votes. If h(f2 ) > v, take a chain of supermajority links g = j0 → j1 → · · · → jn = f2 with every
jl justified. Every jl ⪯ f2 , so no jl is f1 or below f1 (else f1 ⪯ f2 ). Rounds increase along the
chain from 0 ≤ v to h(f2 ) > v, so some l has h(jl ) ≤ v < h(jl+1 ). Let U vote jl → jl+1 and
U ′ vote f1 → c. If h(jl+1 ) = v + 1, then jl+1 ̸= c because f1 ⪯ c, and U ∩ U ′ made double
votes. If h(jl ) = v, then jl ̸= f1 are both justified in round v ≥ 1, and the voters shared by
their two justifying links made double votes. Otherwise h(jl ) < v and h(jl+1 ) > v + 1, so
h(jl ) < h(f1 ) < h(c) < h(jl+1 ) and U ∩ U ′ made surround votes. In each case the slashable
stake is at least W/3.

Example 20.4 (Forks and the overlap). [shown] (a) Three validators of stake 1; g in round 0,

that machine’s toll charges at least 1. (b) Each box goes from down to up along the run, so
some move of each machine raises its box, each costing at least 1. (c) At (s, t) with rA (s) = yes,
a raising step of B at t takes the reading from yes to no.

Theorem 24.4 (A branching run after the raise). [shown] Let x0 , x1 , . . . be a run of a relation
→ on any set S (xn → xn+1 for every n), and let k ≥ 1 with the box down at xk−1 and up at

                                                                             ̸ xq and xp+1 = xq+1 .
So after the raise, the run makes two arrows meet among its own states or never repeats a state.

Proof. Compare xi−d and xj−d for d = 0, 1, . . . , i−k+1. They are equal at d = 0. At d = i−k+1,
xk−1 has the box down and xj−i+k−1 , with j − i + k − 1 ≥ k, has it up, so they differ. At the
least d where they differ, p = i − d and q = j − d give xp ̸= xq and xp+1 = xq+1 .

Remark 24.5. For branching steps Proposition 24.3 says little: in the lambda calculus every term
N is one step from (λx.x)N and from (λy.N )M , for any M and y not free in N . The single-run
statement, Theorem 24.4, applies to one run of any kind of step, including noisy and quantum
steps with infinitely many yes states. Steps in continuous time are not covered.
Remark 24.6. [not claimed] Nothing here is claimed to settle P versus NP, or any question about

Thesis 24.7 (The Thiele thesis). [thesis] Every physical process that computes with final
answers has an exact description as a machine with one next state for every state, given by a
program-computable step on a countable set of states, with inputs placed by a computable map,
on which the answer is a computable box that no run from any input ever turns from up to
down, on accepted and rejected inputs alike.

Argued in Chapter 22 of the book.

Proposition 24.8 (What a final answer accepts). [shown] Let f : S → S on a countable S coded
in N, ι : N → S, and a box r, all computable, with r(f n (ι(x))) = yes ⇒ r(f n+1 (ι(x))) = yes for
every x, n. Let A = {x : ∃n r(f n (ι(x))) = yes}.

 (a) A is listable: some program lists exactly the elements of A.

 (b) Every listable set is the set A of such a description.

 (c) Given Thesis 24.7, every set that a physical process accepts with final answers is listable.

 (d) The condition on rejected inputs is needed: the reading that starts at no, is yes while
     program x is running, and falls to no for good when it stops, is yes for good exactly on the
     programs that never stop, and that set is not listable.

Proof. (a) At round m, run each x < m for m steps and list x if its box is up. If x ∈ A with the
box up at step n, it is up at every later step, so x is listed at round max(n, x) + 1; only elements
of A are listed. (b) Given a listing program, let the state hold an input and a search of the list
for it; on finding it the machine steps from its stopped state to itself forever, and the box reads
whether it has stopped, which nothing turns off. (c) follows from (a). (d) If a program listed
the programs that never stop, running it beside the search for a stop would decide for every
program whether it stops, which no program does.

Proposition 24.9 (Turing’s model makes no mark hold). [shown] For finite sets Q of states
and Σ of symbols, a table is any map t : Q × Σ → Q × Σ × {L, R}. For every table t, every (q, a)

Proof. Every map of that type is a table.

g : S ⇀ S be a partial step, H the states with no next step, ḡ(s) = g(s) for s ∈

Theorem 24.11 (The blindfold). [shown] Let (S, I, δ) be a machine with s0 ∈ S and a list of
moves τ such that x = run(τ, s0 ) ̸= s0 . Let Ŝ = S × {no, yes}, δ̂((s, β), i) = (δ(s, i), β ′ ) with
β ′ = yes when β = yes or δ(s, i) = x and β ′ = no otherwise, ĉ ≡ 1, the box r̂(s, β) = β, and
starts {(s, no) : s ∈ S}. Then:

 (a) (Ŝ, I, δ̂, r̂, ĉ) with those starts is a Thiele machine;

 (b) through the window π(s, β) = s, every run of it is a run of (S, I, δ): π(run(τ ′ , (s, β))) =
     run(τ ′ , s) for every τ ′ , s, β;

 (c) (s, no) and (s, yes) have the same picture and different readings, so no function of the
     picture gives the reading.

So (S, I, δ) is what remains of a Thiele machine when its box is covered by the window π and
the price of every move, settling included, is set to 0.

Proof. (a) β never goes from yes to no; from (s0 , no) the run τ is nonempty and its last step
lands on x, so the box is up at the end; every move costs 1. (b) By induction on τ ′ . (c) By
inspection.
