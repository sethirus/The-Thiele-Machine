Companion lookup material — not included in the book build.

The book contains its mathematical definitions, constructions and arguments.
These files locate and reproduce optional software checks. They are kept in step
with the book's current labels and statement titles.

source-statements.tex: literal proof-assistant declarations and comparisons.
source-index.tex: every numbered result, its section, and the Coq names that check it.
citation-concordance.txt: source-reference contexts, with the same index of results.
tool-history-sources.tex: bibliography for the checking tools.

The TeX extracts are not standalone documents. Checking procedures and the release
receipt are in ../COMPANION_CHECKS.txt.
