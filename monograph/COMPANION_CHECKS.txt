snapshot. The arguments are in the monograph; the snapshot also carries a
formal check of the same statements in Coq, a tool for catching mistakes.
The commands below run that check from the repository root.

Prerequisites
Python 3, GNU make, Coq 8.18 and its standard library, and CSDP. See the
repository's dependency documentation.

Clean reproduction
Run from the repository root:

  python3 scripts/reproduce_coq.py

The script snapshots the sources, regenerates the build file, rebuilds the proofs, and runs the independent module checker. It
reuses no compiled proof from the checkout. Its pass file is written only after all
stages pass. Additional probe files may be supplied with --probe; none run by default.
A failed run can resume from its snapshot:

  python3 scripts/reproduce_coq.py --resume \
    --output artifacts/reproduction/RUN_DIRECTORY

A source change requires a new snapshot. Inspect the full statement, definitions and
derivation of any result being compared with the book; compilation does not perform
that comparison.

Receipt interpretation
The corpus digest fingerprints the listed proof files, their paths, the compiler version, the project manifest, and the five audit scripts.
Comments and runs of whitespace in proof text are normalized, as are designated
claim_not_imply audit-note strings. The Python scripts are tokenized without comments;
version two uses token names instead of Python's numeric token IDs so 3.12 and 3.13
agree. See scripts/assumption_receipt_fingerprint.py for the exact serialization.
Regenerate the receipt after a substantive change to the proof corpus.

Other reproduction commands
Full assumption inventory (regenerate, then compare):
  make assumption-receipt
  make assumption-receipt-check
The custom auditor (its warnings are heuristics):
  python3 scripts/inquisitor.py \
    --report INQUISITOR_REPORT.md
Independent compilation of the small introductory files, the
definition and the smallest machine (also included in the normal
build and audit):
  bash scripts/verify_core.sh
The edition's numbers against the receipt:
  python3 -m pytest tests/test_edition_numbers.py

Tests requiring the proof compiler skip without version 8.18 and a compiled tree.
The custom auditor uses heuristics: a warning requires
inspection and is not itself evidence that a theorem is false.
